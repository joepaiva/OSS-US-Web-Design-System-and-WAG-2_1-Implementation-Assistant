# About this application's chassis

This application was generated by the SD-Agile Platform App Builder using
the **python-fastapi** chassis at version **v1.3.3**.

What this means:

- **Chassis files** (anything under `app/` except `app/slots/`, plus
  `tests/`, `migrations/`, `alembic.ini`, `pyproject.toml`, etc.) come
  from the chassis release. They implement authentication, role-based access
  control, multi-tenancy, audit logging, and observability. **Do not edit
  these files** when iterating on this application — re-running the App
  Builder with a newer chassis version will overwrite local edits.
- **Slot code** under `app/slots/<domain>/` is your business logic. The
  App Builder generated it from your specification. This is what you edit
  when iterating.

## Re-running this build

slot code is preserved; only the chassis files refresh. See the Platform
documentation for the upgrade flow.
